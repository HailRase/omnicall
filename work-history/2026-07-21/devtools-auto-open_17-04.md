# Автооткрытие DevTools при старте

**Дата:** 2026-07-21 17:04
**Статус:** выполнено
**Коммит:** —

## Где
- `src/main/index.ts`

## Что
- В dev-режиме (`!app.isPackaged`) DevTools открывается сразу при создании окна, до `loadURL`/`loadFile`
- Режим `detach`, как у F12-шортката
- Запущен `npm run dev` с новой логикой

## Зачем
- Чтобы успевать видеть ранние логи renderer (создание SDK-сокета) без ручного открытия консоли после старта

## Результат
- Приложение запущено через `npm run dev`; консоль должна открываться вместе с окном
