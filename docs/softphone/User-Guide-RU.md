# Руководство пользователя Axatalk

Краткая инструкция по скачиванию, установке и ежедневной работе в десктопном софтфоне.

Полная установка и сборка: [`install-instruction.md`](../../install-instruction.md) в корне репозитория.

---

## 1. Где скачать

Актуальные установщики — на странице релизов GitHub:

**https://github.com/HailRase/softphone-electron/releases/latest**

| ОС | Файл | Как выбрать |
| --- | --- | --- |
| Windows | `Axatalk-<версия>-win-x64.exe` | Скачать `.exe` |
| macOS (Apple Silicon) | `Axatalk-<версия>-mac-arm64.dmg` | Скачать `.dmg` |
| Linux | `Axatalk-<версия>-linux-x86_64.AppImage` | **Рекомендуется** |
| Linux (Debian/Ubuntu) | `Axatalk-<версия>-linux-amd64.deb` | Только через терминал или GDebi |

Версию можно посмотреть в названии файла или в разделе **О программе** после установки.

---

## 2. Установка (кратко)

### Windows

Запустите `.exe`, пройдите мастер. При SmartScreen: «Подробнее» → «Выполнить в любом случае» (если сборка без подписи).

### macOS

Откройте `.dmg`, перетащите **Axatalk** в **Программы**. При первом запуске разрешите приложение в **Конфиденциальность и безопасность**.

### Linux — AppImage (рекомендуется)

```bash
chmod +x Axatalk-*-linux-x86_64.AppImage
./Axatalk-*-linux-x86_64.AppImage
```

### Linux — `.deb`

**Не используйте двойной клик** — App Center часто закрывается сам. Установка из терминала:

```bash
cd ~/Downloads
sudo apt install ./Axatalk-*-linux-amd64.deb
```

Подробности и обходные пути: [`install-instruction.md`](../../install-instruction.md), раздел Linux.

## 3. Первый запуск

1. Запустите **Axatalk** из меню ОС или ярлыка.
2. Дождитесь исчезновения надписи «Booting application…».
3. Откройте **Настройки** (аватар в шапке → пункт меню).
4. Раздел **Аккаунт** — введите данные SIP от администратора:

| Поле | Пример |
| --- | --- |
| Имя пользователя | `1001` |
| Пароль | пароль SIP |
| Домен | `pbx.example.com` |
| Сервер | `wss://pbx.example.com:7443` |

5. Нажмите **Авторизоваться**.
6. В шапке должен появиться успешный статус регистрации (без ошибки).

При ошибке проверьте учётные данные, URL WebSocket (`wss://` или `ws://`) и доступность сервера через файрвол.

---

## 4. Интерфейс

| Зона | Назначение |
| --- | --- |
| Шапка | Аватар, статус SIP, сворачивание панели |
| Зона звонка | Активная линия, таймер, управление |
| Панель набора | Исходящий вызов, DTMF |
| Настройки | Аккаунт, общие, сессии, диагностика |

Окно компактное (виджет софтфона). Настройки открываются поверх основного экрана.

---

## 5. Исходящий звонок

1. Убедитесь, что SIP зарегистрирован.
2. Откройте **панель набора номера** (иконка клавиатуры).
3. Введите номер.
4. Нажмите кнопку вызова.
5. Разрешите **микрофон**, если ОС запросит впервые.

---

## 6. Входящий звонок

На экране появится карточка входящего вызова с кнопками **Ответить** и **Отклонить**.

---

## 7. Во время разговора

Доступны (в зависимости от состояния линии):

- завершение вызова;
- удержание (hold);
- отключение микрофона (mute);
- DTMF (тоновый набор);
- перевод вызова (если включено в настройках сессий).

При нескольких линиях (если включено в настройках) переключайтесь между активными сессиями в списке линий.

---

## 8. Настройки

Открытие: **аватар** → **Настройки**.

| Раздел | Содержимое |
| --- | --- |
| **Аккаунт** | SIP-логин, пароль, домен, сервер, авторизация |
| **Общее** | Тема, проверка обновлений, о программе |
| **Сессии** | Несколько линий, автоответ, таймауты |
| **Диагностика** | Логи для администратора |

Изменения в аккаунте сохраняются после **Авторизоваться**. Остальные переключатели применяются сразу.

---

## 9. Проверка обновлений

Axatalk **не устанавливает** обновления автоматически — только сообщает о новой версии.

1. **Настройки** → **Общее** → **О программе**.
2. Нажмите **Проверить обновления**.
3. Если версия новее установленной — откроется страница скачивания в браузере.
4. Скачайте установщик с [GitHub Releases](https://github.com/HailRase/softphone-electron/releases/latest) и установите поверх (или по инструкции вашей ОС).

Проверка работает в сборках, собранных с URL manifest (production). В dev-режиме кнопка может быть недоступна.

---

## 10. Частые проблемы

| Симптом | Что делать |
| --- | --- |
| Не регистрируется SIP | Проверить сервер, `wss`/`ws`, сертификат, логин/пароль |
| Нет звука | Микрофон и динамики в настройках ОС |
| Linux: App Center закрылся при `.deb` | `sudo apt install ./файл.deb` или AppImage |
| Linux: приложение сразу закрывается | Запуск из терминала `/opt/Axatalk/axatalk`, см. install-instruction |
| «Проверка обновлений недоступна» | Нужна production-сборка с manifest URL |
| Windows SmartScreen | «Подробнее» → «Выполнить в любом случае» |

Логи: **Настройки → Диагностика**.

---

## 11. Требования к SIP-серверу

- SIP поверх WebSocket (совместимость с JsSIP).
- Для `wss://` — валидный TLS-сертификат.
- Учётная запись с правом регистрации и звонков.

По настройке PBX обращайтесь к администратору телефонии.
